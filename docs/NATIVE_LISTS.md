# 네이티브 목록·계층·편집 표면

`ListModel`은 안정적인 문자열 키·부모 키·텍스트·활성·체크 상태를 가진 값 모델이다. 부모 누락·중복 키·순환·64단계 초과 계층과 100,000행 초과 입력을 커밋 전에 거부한다. 선택은 데이터 리비전을 바꾸지 않으며 확장은 원본 행을 변경하지 않는다. 문서의 dirty/save/history는 목록 모델이 소유하지 않는다.

`List`와 `Hierarchy`는 같은 네이티브 가상 목록을 사용한다. 화면 안의 행만 벡터로 그리며 이름 편집기는 하나를 재사용한다. 키 선택·확장/축소·키보드 이동·유니코드 이름 변경·드래그 순서/부모 변경·체크 토글을 제공한다. 소비자는 명시적인 선택·이름·순서·체크 콜백을 받아 문서 명령으로 적용한다. 저장 거부 시 권위 있는 문서 상태로 `set_rows`를 다시 호출한다.

구성 위젯의 수는 행 수와 독립적이다. 스크롤·선택·화면 크기 변경은 문서를 수정하지 않는다. 모델은 owner thread에서만 변경하며, WidgetBuilder가 뷰의 관측 lease를 보유한다. 마운트 해제 후에는 모델 변경이 폐기된 화면을 호출하지 않는다.

`Widgets::app_card`는 네이티브 스택에 반응형 배경을 그리는 카드이다. `list_item`은 목록 밖에서도 쓸 수 있는 평면 액션 행이다. `event_listener`는 WidgetInput과 크기 변경을 받는 보유형 그리기 표면이며 제품의 편집 캔버스를 위젯 트리 안에 통합한다.

LVUI AOT와 HTML 태그는 `AppCard`, `EventListener`, `List`, `ListItem`, `Hierarchy`를 직접 C++ 호출로 생성한다. 일반 속성은 Core Observable에 바인딩하고 동적 행은 명시적 ListModel에 바인딩한다. `LVRS.native_list_*`는 순환/스레드/불변성, 실제 이름 편집·카드·수명, 20,000행 가상 표시를 검사한다.

## 설치 ABI 일치 검사

네이티브 위젯·창·그래픽 값의 공개 헤더 해시를 iiGUI 패키지에 기록한다. LVRS는 빌드한 iiGUI의 ABI 식별자를 설치 Config에 보존하며, 같은 버전 번호라도 다른 식별자의 키트와 조합하면 구성 단계에서 거부한다. 공개 Snapshot 크기가 다른 라이브러리를 연결하여 실행 중 스택이 손상되는 문제를 예방한다. `LVRS.native_package_abi`는 일치·오래된 식별자·식별자 누락의 세 구성을 검사한다.

페이지 콘텐츠의 기본 버튼은 기존 iiGUI 입력 계약을 따른다. Enter/Space 누름에서는 pressed 상태만 바뀌고, 해제에서 활성화한다. 라우터 입력 검사는 포인터와 키의 누름·해제를 모두 전달하고 키 해제 전에는 명령이 실행되지 않음을 확인한다.
