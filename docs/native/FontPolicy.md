# 네이티브 FontPolicy

원본 `backend/fonts/fontpolicy.*`의 속성 5개, invokable 6개, 정적 부트스트랩 3개를 C++23으로 제공한다. `iiGUI::FontDatabase`를 주입해 플랫폼 글꼴 조회와 애플리케이션 상태를 분리한다. 기본 생성자는 UI 스레드의 기본 글꼴 서비스를 사용하며 명시적 생성자는 독립 환경을 사용한다. 정책 인스턴스는 LVUI 뷰 scope가 소유한다.

선호 가족명은 Pretendard이다. 탐지에는 대소문자를 무시한 정확한 일치를 우선하고 이후 포함하는 가족명을 사용한다. 실제 fallback 적용은 원본처럼 목록에서 처음 발견한 포함 일치를 사용한다. 현재 애플리케이션 가족명에 Pretendard가 포함된 경우의 조기 성공, 생성자에서 경고를 만들지 않는 동작, 실패하고 가족도 없을 때만 경고하는 동작을 보존한다. 이름만으로 판단한 성공은 실제 glyph 출력의 증명이 아니다.

`refresh()`는 공급자의 목록을 갱신한 뒤 effectiveFamily와 pretendardAvailable을 한 묶음으로 알린다. lastWarning은 독립적으로 변경 시에만 알린다. `resolveFamily`는 요청의 공백을 제거하고 실제 목록에 있으면 요청한 철자를 유지하며, 없으면 현재 effectiveFamily를 사용한다. 수치·스타일 조회는 iiGUI의 같은 7개 원본 토큰을 사용한다. 알 수 없는 크기는 인자로 받은 fallback을 유지한다.

| 크기 | 굵기 | 스타일 |
|---|---|---|
| 26·22 | 700 | Bold |
| 17·15·12 | 600 | SemiBold |
| 13 | 500 | Medium |
| 11 | 400 | Regular |

정적 등록은 번들 10개와 원본 대체 대상 8개를 사용한다. Theme의 최초 네이티브 appearance도 같은 정책으로 부트스트랩한다. 등록은 scope 재평가나 hover마다 반복하지 않는다. 표시 갱신은 위젯 트리의 글꼴 측정 캐시를 갱신하며 사용자 파일·생성 작업 상태를 수정하지 않는다.

LVUI import·일반 바인딩·Static 값과 명령 참조를 실제 생성 C++로 연결하는 예제 및 회귀 검사를 유지한다. 원본 전체의 상속 API·스타일·플랫폼 동작이 입증되기 전에는 완전 이식으로 표시하지 않는다. LVRS 앱·테스트 실행은 저장소 지침에 따른 전체 작업 마지막 일괄 검증에 유보한다.
