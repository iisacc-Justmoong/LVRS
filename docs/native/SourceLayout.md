# 네이티브 소스 구조

네이티브 공개 헤더와 구현을 `src/` 아래 UI 구성 요소, 컨트롤, 계층·목록·표, 모델, 탐색, 텍스트, 미디어, 스타일, 모니터링, 플랫폼, 오버레이 책임으로 나눈다. 같은 이름의 헤더와 구현은 같은 디렉터리에 둔다. 레거시 Qt/QML 원본은 기존 위치를 유지한다.

빌드용 연결 헤더와 설치된 원본 헤더는 기존 `<LVRS/...>` 경로를 유지한다. `LVRS.native_source_layout`과 네이티브 대응표의 소스 인벤토리는 새 위치를 확인한다. 이 구조 변경은 레거시 기능과 네이티브 구현의 완전한 동등성이나 다른 플랫폼의 실행을 증명하지 않는다.

설치된 LVUI가 `LVUI_AOT_FRAMEWORKS`에 LVRS를 제공하지 않으면 과거 `FRAMEWORK LVRS` 전용 통합 픽스처는 건너뛴다. 헤더·소스와 현재 iiGUI 기반 LVRS 자체 검사는 계속 빌드하며, 구버전 패키지의 기존 동작은 유지한다.

`tests/native/layout_consumer`는 설치된 LVRS와 일치하는 iiGUI 패키지에서 서로 다른 책임의 공개 헤더를 포함하고 모델 API를 호출한다. 이를 통해 원본 디렉터리뿐 아니라 설치된 헤더 경로와 가져온 CMake 타깃도 확인한다.
