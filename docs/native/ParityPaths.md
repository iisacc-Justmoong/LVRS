# 네이티브 대응표의 플랫폼 공통 경로

`catalog/native/parity.json`의 경로는 저장소 상대 경로이며 `/`로 직렬화한다.
Windows의 `Path` 문자열을 그대로 기록하면 `src\LVRS\Alert.cpp`가 되어
macOS·Linux에서 생성한 대응표와 다르게 판정된다.

생성기는 `relative_to(root).as_posix()`를 사용하며 직렬화할 문자열을 기준으로
정렬한다. 파일의 정체성·내용 해시·기능 지원 상태는 경로 구분자와 별개의 계약이다.
줄바꿈을 정규화하는 기존 소스 해시 규칙도 유지한다.

`LVRS.native_parity`는 상대 경로의 플랫폼 왕복, 직렬화 순서·중복 부재와
전체 소스 해시를 반영한 대응표 재생성 일치를 검사한다. 경로 보정은
어떤 구성 요소도 `complete`로 승격하지 않는다.
