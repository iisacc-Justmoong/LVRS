# 네이티브 SVG 서비스와 표시 경계

`SvgManager`는 원본의 속성 6개·조회/명령 4개·setter 4개를 네이티브 C++로 제공한다.
초기 값은 vectorFirst=true, minimumScale=3, maximumScale=4, cacheSize=256,
revision=0이다. `SvgSource`는 플랫폼·파일·네트워크 접근을 교체하는 인터페이스이다.
LVUI는 값과 명령을 연결하고 소스 판독·리디렉션·PNG 변환·캐시를 실행하지 않는다.

## 소유와 요청

기본 생성자는 내장 LVRS 아이콘·파일·data URL을 지원한다. 원격 소스는 애플리케이션이
소유하는 iiSDKCore EventLoop를 생성자로 전달한다. 별도 이벤트 루프·추론 런타임·작업당
스레드를 만들지 않는다. 해당 루프는 정책과 진행 중 요청보다 오래 살아야 한다.
display scale 공급자는 활성 창이나 애플리케이션의 실제 배율을 반환하도록 주입한다.
창 없는 기본 문맥의 배율은 1이다. 애플리케이션 리소스 네임스페이스도 resolver로 주입한다.

파일 판독은 iiFileProvider Native, HTTP는 iiNetwork, 래스터화는 iiGUI,
PNG 인코딩은 iiVisualCodec의 Image 구성만 사용한다. Video·USD 구성은 요구하지 않는다.
상대 리디렉션은 [libcurl URL API](https://curl.se/libcurl/c/curl_url_set.html)로 해석하고,
[원본의 리디렉션 정책](https://doc.qt.io/qt-6/qnetworkrequest.html#RedirectPolicy-enum)처럼
HTTPS에서 HTTP로 내려가는 전환을 거부한다. 전송 대기/정체 제한은 5초이며 전체 요청의
6초 기한을 리디렉션에서도 이어 간다. 본문·SVGZ 해제 결과는 각각 1 MiB로 제한한다.

완료 콜백은 fetch 반환 이후 소유 루프에서 전달한다. 같은 canonical key의 요청은
하나로 합친다. 정책이 닫히면 소유한 요청과 예약된 전달을 취소하고 늦은 완료를 무시한다.
다른 스레드의 잘못된 완료는 상태에 반영하지 않는다. 일반 조회는 통지 중에도 허용하고
재진입 명령은 거부한다. 수신 오류는 이미 반영한 상태를 롤백하지 않으며 다른 변경 통지도
계속 전달한다. 동기 완료를 보내는 공급자는 계약 오류로 보고한다.

## 원본 값과 캐시

`icon()`은 벡터 우선 모드에서 SVG/SVGZ URL을 유지한다. 래스터 모드에서는 원본처럼
논리 크기 1..2048, 요청/기기/최소/최대 배율 및 소수 셋째 자리 캐시 키를 사용한다.
`image()`는 네이티브 위젯용 불변 RasterImage를 반환한다. 같은 키의 이미지는 정체성을
유지하며, 이 경로는 PNG를 만들거나 data URL을 다시 디코딩하지 않는다. PNG는 icon의
래스터 문자열이 요청될 때만 지연 인코딩한다.

래스터 LRU는 항목 수와 실제 바이트 예산을 함께 지킨다. 기본 래스터·원격 소스 예산은
각각 64 MiB이고 진행 중 요청은 기본 최대 64개이다. 래스터 예산의 설정 상한은 512 MiB,
소스 예산의 설정 상한은 64 MiB이다. 소스 캐시는 최대 4096개이며 키·객체·본문을 함께
계산한다. 이 예산은 외부 이미지 소유자와 allocator의 전체 RSS 한도를 의미하지 않는다.
예산을 넘는 큰 래스터는 반환하되 캐시에
유지하지 않는다. 원격 소스를 담을 수 없으면 오류를 게시하고 재시도 통지 루프를 만들지
않는다. clearCache는 비어 있으면 revision을 바꾸지 않고 진행 중 요청도 유지한다.
vectorFirst 변경과 cacheSize=0의 무효화 순서는 원본 계약을 따른다.

iiGUI ImageBudget으로 원본 기본 최대 배율의 8192×8192까지 명시적으로 요청할 수 있다.
GPU 업로드 성공은 별도 검증 대상이며, 더 큰 배율/메모리 요청은 명시적 오류로 반환한다.
iiGUI 기본 이미지 예산과 텍스트 캐시 한도는 변경하지 않는다.

## 검증 범위와 남은 동등성

원본 두 파일의 해시·클래스 API·초기 값은 native_svg_contract.py로 대조한다. 이 자료는
Qt를 실행해 수집한 동작 oracle이 아니다. 네이티브 정책 32개, 로컬 HTTP fixture 6개와
생성 뷰 8개를 컴파일 대상으로 준비하며 LVRS 실행은 전체 작업의 마지막에 수행한다.
Image 뷰는 소스·크기·맞춤·색상·모서리·표시 옵션을 C++로 갱신하고 기존 노드를 유지한다.

전체 QUrl 사용자 입력 추론, 모든 애플리케이션 리소스 등록, 스크린 변화와 실제 픽셀,
SVG 필터/동작/서체의 원본 렌더러 동등성 및 플랫폼별 실행은 계속 검증해야 한다.
상대 경로는 명시적인 로컬 파일로 해석하며 존재하지 않는 파일명을 암묵적 웹 주소로
추정하지 않는다. 이 문서의 구현 범위를 전체 LVRS/LVUI 완료로 표시하지 않는다.

생성 뷰의 그리기 검사는 iiGUI의 공개 `drawing_snapshot` 결과를 사용한다. 내부 전용
`frame` 함수를 직접 호출하지 않으며, 스냅샷의 소유 스레드·닫힘 오류도 검사 보조 코드가
명시적으로 처리한다. 비공개 호출로 발생한 최초 컴파일 실패는 검증 이력에 보존한다.

현재 검증용 iiVisualCodec Image 아카이브의 Mach-O 최소 macOS 버전은 27.0이다.
외부 이미지 라이브러리에도 27.0 링크 경고가 있으므로, LVRS의 12.0 링크 설정만으로
12.0 배포를 지원한다고 판단하지 않는다. 배포용 코덱 재빌드, 외부 라이브러리의 배포
최소 버전과 재배치 가능한 의존성 묶음은 별도 검증해야 한다.

AOT의 전송 오류 검사는 소유 실행 영역에서 외부 비동기 완료를 직접 전달하여 수행한다.
일반 UI 명령의 보수적인 백엔드 revision 갱신으로 같은 이미지 조회를 다시 요청하는
경우와 구분한다. 오류 표시·원천 전환 후 복구·파일 revision 비변경을 실제 바인딩에서 확인한다.
