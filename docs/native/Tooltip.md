# 자체 네이티브 Tooltip

원본 Tooltip.qml의 위·아래·좌·우 후보 순서, 선호 방향, 최대 면적 대체, 여백·꼬리 길이, 모서리를 가진 말풍선 경로를 C++23으로 옮겼다. TooltipLayout은 앵커와 콘텐츠·가용 사각형을 받아 전역 body/bounds와 방향을 반환한다. tooltip_outline은 해당 배치의 로컬 SVG path를 생성한다. 같은 위젯에 PanelMaterial의 glass25 재질과 실제 scroll_view를 합성하며 OS 툴팁 컨트롤은 생성하지 않는다.

기본값은 지연 500ms·타임아웃 5,000ms·숨김 지연 120ms, 최대 320×320, 콘텐츠 여백 12, 가장자리 여백 8, 반경 12, 꼬리 길이 10·너비 16이다. target은 약한 위젯 핸들이며 anchor_point는 대상 로컬 좌표이다. 생략하면 중앙이다. 대상이 없으면 anchor_point는 콘텐츠 표면 좌표이고 기본값은 (0,0)이다. available_rect가 없으면 표면 전체를 사용하며 지정하면 실제 표면과 교차한다.

## 수명·자동 표시

독립적인 iiGUI WidgetInteractionPort로 대상과 말풍선을 관찰한다. 기존 버튼의 입력·포커스 핸들러를 교체하지 않는다. 대상 hover/press/focus에서 표시를 요청하고, 대상이나 본문에 마우스가 있는 동안 숨김 지연을 취소한다. 대상이 숨겨지거나 비활성·폐기되거나 앵커가 클립 밖으로 나가면 닫는다. 말풍선 자체는 열 때 포커스를 가져오지 않는다. 꼬리는 그려지되 입력 사각형에서 제외하므로 원래 컨트롤의 클릭과 포인터 캡처를 유지한다.

표시·숨김·타임아웃·닫힘 handoff guard는 해당 뷰의 Core TaskScope가 소유하는 한 번의 deadline 작업이다. 별도의 이벤트 루프나 스레드를 만들지 않는다. 취소·세대 종료는 남은 작업을 회수한다. 자동 닫힘 후 같은 대상의 hover/focus가 유지되면 바로 다시 열지 않고, 실제로 대상에서 벗어나거나 자동 모드/대상을 교체한 뒤 재무장한다.

내용·배치·색상 옵션 갱신은 닫힘 latch와 기존 타임아웃을 유지한다. timeout 값 자체를 변경한 경우에만 다시 예약한다. 대상 교체는 이전 말풍선을 닫고 새 대상으로 표시 조건을 판단한다. 잘못된 외부 도메인·폐기 대상·옵션은 현재 대상을 해제하기 전에 거절한다. Core admission이 거절되면 명시적 API는 Result 오류를 반환하고, 자동 관찰/예약 콜백의 실패는 state.last_error에 기록한다. 잘못된 스레드에서 디스패치된 예약은 UI를 건드리지 않고 wrong_executor를 기록한다.

## 콘텐츠·렌더링

기본 콘텐츠는 네이티브 폰트로 줄 바꿈하는 body 레이블이다. 실제 폭으로 measure한 높이를 사용하며 문자 수로 줄 수를 추정하지 않는다. 후보 방향이 좁은 폭을 선택하면 다시 그 폭으로 측정한다. 충분한 콘텐츠 영역이 없거나 8,192 프레임 예산을 넘으면 내용을 잘라 저장하거나 비정상 크기를 할당하지 않고 표시를 거절한다.

TooltipContentFactory는 마운트 시 한 번 C++ 자식을 구성한다. 닫기는 콘텐츠를 파괴하지 않으며 다시 열 때 스크롤만 0으로 돌린다. 임의 레이블·버튼·뷰를 콘텐츠로 사용할 수 있다. set_options, set_target, open, open_at, close, refresh와 state/options를 제공한다. open은 delay를 적용한다. 원시 root 팝업 API는 상위 컨트롤러의 표시 지연을 우회하므로 일반 앱은 Tooltip API를 사용한다.

PanelMaterial을 통해 팔레트·그라디언트·blur·테두리·그림자를 그린다. 스타일이나 배치가 바뀔 때만 재질 구성을 갱신하며 동일 마스크/그라디언트는 기존 재질 캐시를 사용한다. 전역 Theme와 모션 설정의 완전한 원본 동등성, 모든 플랫폼 GPU의 픽셀 결과는 아직 검증하지 않았다.

## LVUI와 남은 범위

Tooltip 예약어는 실제 Tooltip::create를 부르는 C++23으로 생성된다. targetId는 같은 구성 스코프의 앞/뒤에 선언한 위젯을 연결하며 target에는 typed C++ 위젯 멤버도 전달할 수 있다. 둘은 함께 사용하지 않는다. {}의 자식은 유지되는 콘텐츠 팩토리로 구성한다. 텍스트·크기·시간·색상·동작 입력은 동일 인스턴스에 바인딩한다. 숫자 시간은 유한하고 하루 이내인지 검사한 후 밀리초로 변환한다.

원본과 완전 동등하지 않은 범위는 자동 OS safe-area/물리 화면 교차 관찰, 모든 임의 transform/outline 픽셀, 원본과 별도인 160ms opacity와 420ms scale 곡선의 분리, 동적 contentComponent 교체·별도 로더 스코프, 전체 상속 Popup/ToolTip API·모바일 제스처·고급 접근성이다. 가용 영역은 현재 명시적으로 제공할 수 있다. AOT의 초기 open/visible 명령과 다른 콘텐츠 스코프의 targetId는 아직 제공하지 않는다.

tests/native/tooltip_layout.cpp·tooltip.cpp, iiGUI 상호작용 검사와 LVUI AOT 검사를 함께 컴파일한다. 실행은 전체 LVRS 이식의 마지막 일괄 단계까지 보류한다. 빌드·설치 소비자·정적 감사와 실제 창·입력·시간·픽셀 통과 증거는 구분한다.
