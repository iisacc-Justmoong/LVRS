# ColorPicker assets

`hue-ring.png` is the unmodified 448 × 448 Figma export from ColorPickerPanel / Wheel (`885:43344`), rendered at 224 × 224 logical pixels. The source component set is `885:44522` in file `0GkItQYSNIR0lZ3iJhfJzc`.

The ring's red origin is at the bottom; hue advances counterclockwise in screen coordinates. Interactive color planes and the triangle are rendered from current channel values by `ColorPickerSurface`. The eyedropper reuses LVRS `resources/iconset/imagecolorPicker.svg`, the same scaled source glyph as the Figma action.
