# 네이티브 생성 작업 공간 예제 지침

이 예제는 Dreamscapes 제품을 변경하지 않고 LVUI·iiGUI로 필요한 뷰를 작성할 수 있는지
검증한다. C++23, 실제 iiGUI 위젯·그리기·입력과 iiSDKCore 작업·프레임 루프를 사용한다.
절차적 RGBA 렌더링을 AI 추론이나 제품 생성 기능의 실행 결과로 표현하지 않는다.
코드와 헤더는 App/에 함께 두고 docs/·tests/를 갱신한다. 빌드 디렉터리는 build/이다.
앱·self-test 실행은 전체 준비 검증의 최종 일괄 단계에 수행한다. 사용자 데이터와 활성
프로세스는 보존하고 시스템 SDK 설치는 별도 검증된 패키지에서 수행한다.
