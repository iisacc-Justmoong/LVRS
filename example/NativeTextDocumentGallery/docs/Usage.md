# 문서 모델 갤러리

LVUI는 네이티브 C++ 위젯을 생성하고 iiGUI가 직접 그린다. Core가 진입점·이벤트·작업·
프레임과 스코프 수명을 소유한다. 파일 작업은 iiFileProvider Native를 사용한다.

인자 없이 실행하면 메모리 예제를 표시한다. --document PATH는 파일을 읽거나 없는 파일을
빈 연결 문서로 만든다. Next line은 조회 위치만 바꾸고 Insert/Undo는 범위 편집 이력을
사용한다. Save는 명시적 요청이며 목적지가 없으면 안내를 표시한다. 임의 기본 경로에 저장하지 않는다.
이 예제는 로드가 끝나기 전 편집과 불완전하거나 실패한 로드 결과의 저장을 거절한다.

화면은 줄 하나를 최대 2048바이트의 UTF-8 경계로 제한해 보여준다. 전체 문서를 reactive
문자열로 구체화하지 않는다. 별도의 CodeEditor 갤러리에서 PlainText 화면을 제공하며,
이 예제 자체는 다중 행 편집 화면이나 RichText TextEditor의 완성본이 아니다.
해당 화면과 리치 서식·선택·IME 및 전체 플랫폼 동등성은 같은 이식 목표의 남은 작업이다.

--self-test BUILD_DIRECTORY는 iiFileProvider로 청크 입력을 만들고 로드·범위 수정·undo·
원자적 저장·조회 무변경·백그라운드 결과·크기 변경·정상 종료와 백엔드 1회 수명을 확인하도록
등록했다. 모든 실제 실행은 전체 LVRS 작업의 마지막 일괄 단계로 보류한다.

설치 스크립트는 컴파일·설치만 수행한다. Qt 검색을 끄며 설치 패키지 경로를 CMake 인자로
전달할 수 있다. Workspace의 별도 설치 소비자와 전역 설치본 갱신을 구분한다.
