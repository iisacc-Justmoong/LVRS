# Card·Avatar 갤러리

LVUI의 모든 카드 종류와 세 아바타 크기를 같은 Backend 한 개로 구성한다.
백그라운드 Core 작업이 불변 RGBA 이미지를 만들고 owner 이벤트 루프로 전송한다.
타이머 대신 Core 프레임 루프의 unscaled end 단계가 종료 검사를 담당한다.
메타데이터·진행률·선택·행·이미지·커스텀 팩토리는 기존 C++ 위젯을 유지하며 바뀐다.

빌드: 설치된 Native LVRS와 Core·iiGUI·LVUI 패키지 경로를 지정해 install.sh를 사용한다.
기본 산출물은 build/와 build/install이다. 시스템 설치본을 자동 교체하지 않는다.
실행 시 --self-test는 선택·내부 액션·사용자 프리뷰·배경 결과·리사이즈·정상 종료를 검사한다.
현재 이 실행은 전체 작업 최종 일괄 단계로 보류되어 있다.

원본 URL 로더/Qt 비동기 캐시 대신 준비된 RasterImage를 받는다. 외부 파일의 읽기·
디코딩·취소는 앱/리소스 계층이 맡는다. 커스텀 자식의 둥근 clip, 전체 motion·AX·상속
API 및 타 플랫폼 실행은 아직 동등성이 완료되지 않았다.
