# Native material gallery

Qt-free C++23 LVUI AOT example for MaterialSurface, PanelMaterial and WindowMaterial.
Shows captured and standalone blur, eight accent gradients, a custom silhouette, cached masks,
shared Core frame motion, retained editor state and background-result delivery.

Build using the installed Native LVRS package. `install.sh` stages into `build/install` by default
and never runs tests or opens the app. Runtime validation remains deferred to the final whole-goal
batch. See [usage](docs/Usage.md) and the SDK material documentation for remaining contracts.
