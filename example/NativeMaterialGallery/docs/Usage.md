# 머티리얼 갤러리

네 가지 표면에 같은 스코프의 반응형 악센트·밀도·Motion을 연결한다. 배경 패턴은 일반
네이티브 패널이고 캡처/독립 머티리얼, 꼬리를 가진 임의 경로, 같은 마스크의 그림자를
보인다. Core 작업 결과는 owner 이벤트 루프로 반영한다. 색상·크기 갱신 중 편집 중인
자식과 백엔드를 유지한다. 종료와 프레임은 Core가 소유한다.

설치된 Native LVRS와 iiGUI·Core·LVUI 경로를 install.sh의 추가 CMake 인수로 제공한다.
기본 build/와 build/install은 예제 내부이다. 전역 설치본을 자동 교체하지 않는다.
--self-test는 배경 결과·프레임·GPU 기능·자식 보존·리사이즈·정상 종료를 검사한다.
현재 앱과 self-test 실행은 전체 LVRS 전환 마지막 일괄 단계까지 보류되어 있다.

임의 Item 두 개의 별도 캡처·완전한 글로벌 Theme·모든 플랫폼 동등성은 후속 계약이다.
컴파일·정적 패키지 검증은 실제 픽셀·성능·런타임 통과와 구분한다.
