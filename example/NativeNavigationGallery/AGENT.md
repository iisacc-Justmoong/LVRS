# 네이티브 탐색 모델 예제 작업 지침

이 예제는 LVUI AOT·iiGUI 자체 위젯과 C++23 탐색 모델을 연결한다.
앱 소스는 `App/`, 문서는 `docs/`, CTest 등록은 `tests/`에 둔다.
빌드 출력은 `build/`에 두며 `install.sh`는 앱을 실행하지 않고 빌드·설치만 수행한다.

현재 사용자 요청에 따라 테스트와 앱의 실제 실행은 전체 작업의 최종 일괄 단계에 모은다.
빌드 성공을 실행 성공으로 표현하지 않는다. 모델 경로 표시 예제를 완성된 PageRouter
페이지 호스트라고 표현하지 않는다. scope 소유 backend와 Core 포트의 약한 수신 수명을 유지한다.
