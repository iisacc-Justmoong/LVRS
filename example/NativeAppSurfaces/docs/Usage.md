# 네이티브 앱 헤더와 카드 예제

AppHeader의 기본 자식은 actions 행, AppCard의 기본 자식은 content 슬롯에 구성한다.
모두 같은 iiGUI 위젯 세대와 LVUI C++ 백엔드 스코프를 사용한다. 새 OS 컨트롤이나
별도의 자식 소스 해석기를 만들지 않는다.

Menu는 compact와 제목을 바꾸고 Update card는 카드 제목·부제를 바꾼다. Shape는
둥근 사각형과 원통형 외곽을 전환한다. 본문의 입력 필드와 체크박스는 같은 객체를
보관한다. 창 크기 변경은 공유 앱 모델의 치수 Observable에 전달한다.

백엔드는 스코프당 한 번 생성하며 앱 상태가 공유하는 모델은 백엔드 수명과 별개이다.
Core가 작업자 결과 42를 UI 실행기로 반영하고 표시 프레임과 정상 종료를 소유한다.
self-test에는 compact 메뉴 치수, 기본 슬롯 배치, 본문 객체/편집 값 보존, 스코프
생성·해제 1회, 작업자 결과·크기 변경·프레임·종료를 등록한다.

현재는 코드 생성·컴파일·링크·설치 소비자 정적 검사만 수행한다. 사용자 지시에 따라
앱·테스트·self-test 실행은 전체 작업의 마지막 일괄 단계로 미룬다. 설치 스크립트도
실행 검증을 자동 호출하지 않는다.

목록 도구 막대·푸터와 모델/수동 계층 도구 막대도 같은 SurfaceBackend를 사용한다.
불변 공유 구성 포인터를 교체해 아이콘과 모델을 갱신하며 self-test는 기존 버튼 핸들과
스코프를 유지하는지 검사한다. 추가 검사 역시 전체 작업 최종 일괄 단계까지 실행하지 않는다.
